# Деньги

Минималистичное Android-приложение личного капитала: Сбер и OKX, цель, история капитала, категории, правила магазинов и разделение покупок.

## Обновление на телефоне

Настройки → **Обновить приложение**. Приложение получает опубликованную версию GitHub, проверяет SHA-256, размер, applicationId, номер версии и подпись, затем открывает подтверждение Android. Данные остаются на телефоне. Не удаляйте приложение перед обновлением.

- [Последний релиз](https://github.com/rnghx/money-android/releases/latest)
- [APK](https://github.com/rnghx/money-android/releases/latest/download/app.apk)
- [Исходники релиза](https://github.com/rnghx/money-android/releases/latest/download/source.zip)
- [Манифест обновления](https://github.com/rnghx/money-android/releases/latest/download/update.json)

## Разработка и выпуск без постоянного проекта на ПК

Все текущие исходники — обычные файлы этого Git-репозитория. Сборка и подпись выполняются на временном сервере GitHub Actions. Ключ прежней подписи хранится только как защищённый Actions secret `ANDROID_KEYSTORE_BASE64`, а не в Git или APK.

1. Внести изменения, увеличить versionCode и versionName.
2. Запустить локально только необходимые проверки или дождаться cloud-проверок.
3. Отправить коммит в main.
4. В Actions запустить **Android release** (либо dispatch через GitHub API/CLI).
5. Дождаться успешного workflow и проверить публичный манифест и хеш APK.
6. На телефоне нажать «Обновить приложение».

Следуйте [AGENTS.md](AGENTS.md) и [общим инструкциям](docs/ANDROID-APPS.md). Постоянные папки проектов и APK на рабочем столе не требуются. Для изменений в коде агент может использовать временную рабочую копию и удалить её после проверки публикации.

Запросы Сбера/OKX выполняются только вручную; ключи аккаунтов остаются зашифрованными на телефоне. Сбер использует неофициальный протокол и может присылать уведомления о ручном входе. История капитала собирается из наблюдавшихся остатков, без выдуманных прошлых значений.
